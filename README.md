# Gacha Forge 한글화 보완판 v1.0.21

[원본 GACHA-FORGE-UI-KR](https://github.com/marittini/GACHA-FORGE-UI-KR)를 기반으로 한 비공식 번역 보완판입니다.

## 주요 기능 및 변경 사항
- 홈 캐릭터 화면의 `Home unit`, `In use`, 속성 및 직업 표시 등 누락된 UI 번역을 보완했습니다.
- 4★ 캐릭터가 없을 때 표시되는 영어 안내 문구를 번역했습니다.
- 소환 결과 화면의 `Glimmer`를 `글리머`로 표시하도록 보완했습니다. (v1.0.21)
- 기존 전투 상태 효과 및 이벤트 UI 번역 기능을 유지했습니다.
- 확장 표시 버전을 1.0.21로 통일했습니다.

## 설치 및 업데이트 방법
1. 마리나라에 GitHub 확장 관리자를 설치해 주세요.
2. 마리나라 설정 → Addons → External Extensions → **GitHub 확장 관리**를 열어 주세요.
3. 이 저장소의 공개 GitHub 주소를 붙여넣고 **패키지 찾기**를 선택해 주세요.
4. 확장을 선택하고 코드와 권한을 검토한 다음 설치해 주세요.
5. 마리나라에서 실행을 승인하고 페이지를 새로고침해 주세요.

기존 설치자는 GitHub 확장 관리자의 **업데이트 확인** 기능을 이용해 주세요.

> 다른 한글화 확장과 함께 사용하면 번역이 중복 적용될 수 있으므로 동시 활성화는 피하는 것을 권장합니다.
