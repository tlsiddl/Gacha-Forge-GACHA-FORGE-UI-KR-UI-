# 가챠포지 통합 한글화 (Gacha Forge UI KR) v1.8.4

원작자 [marittini의 GACHA-FORGE-UI-KR](https://github.com/marittini/GACHA-FORGE-UI-KR) v1.7.3을 기반으로 기존 보완판 v1.0.21의 누락 번역 처리를 통합한 개인 확장입니다.

**이제 원본 확장과 보완 확장을 따로 설치할 필요 없이, 이 확장 하나로 사용하실 수 있습니다.**

## 포함된 기능

- 원본의 고정 UI·시스템 설명 한글화와 방대한 번역 사전을 유지했습니다.
- 원본의 스토리 묶음 번역, 오류 진단 및 모바일 입력 보강 기능을 유지했습니다.
- 홈 캐릭터 화면의 직업·속성 및 사용 상태 표시 번역을 보완했습니다.
- 캐릭터가 없을 때 표시되는 안내 문구를 번역했습니다.
- 소환 결과 화면에서 `Glimmer`가 `글리머`로 표시되도록 보완했습니다.
- 새로 나타나는 UI 요소를 관찰해 번역이 누락된 화면을 다시 검사하도록 했습니다.
- 생성된 스토리나 사용자 지정 이름을 임의로 번역하지 않도록 고정 UI 번역 범위를 제한했습니다.

## 설치

1. 마리나라의 **GitHub 확장 관리**에서 이 저장소 주소를 등록해 주세요.
2. `manifest.json`에 표시되는 **Gacha Forge 통합 한글화**를 설치해 주세요.
3. 기존 **Gacha Forge UI 한글화** 또는 **Gacha Forge 한글화 누락 보완** 확장을 사용 중이라면 비활성화해 주세요. 동시에 켜면 중복 처리가 발생할 수 있습니다.
4. 확장 실행을 승인하고 가챠포지 화면을 새로고침해 주세요.

새 버전이 올라오면 GitHub 확장 관리자의 **업데이트 확인**을 이용해 주세요.

## 통합 버전 기록

- **v1.8.4:** Gacha Forge 공식 클라이언트의 패시브 발동 조건, 보스 특수 상태와 전투 툴팁 생성 문구를 분석해 한글화를 추가했습니다. 기존 스토리 번역 및 홈·성장·소환 기능은 유지합니다. 일부 조합형 효과는 추가 확인이 필요합니다.

- **v1.8.4:** 전투 화면 내부에 포함되지 않은 궁극기 팝업에서도 엄격하게 일치하는 공식 전투 설명이 번역되도록 범위 제한을 수정했습니다.

- **v1.8.4:** 공식 Gacha Forge v1.8.12 소스에서 추출한 공격·광역 궁극기·회복·보호막·중독·기절·버프 상태 설명의 동적 번역 패턴을 추가했습니다. 문구와 수치는 그대로 보존하며, 게임 내 모든 화면에서의 검증은 추가로 필요합니다.

- **v1.8.4:** 전투 버프·디버프 수치, 패시브 효과 출처, 남은 라운드 등 조합형 전투 툴팁 번역을 보강했습니다. 공식 Gacha Forge 소스의 생성형 문구 구조를 고려했으며, 모든 신규 문구의 실기기 검증이 완료된 것은 아닙니다.

- **v1.8.4:** 원본 v1.7.3 전체 기능과 보완판 v1.0.21의 화면 번역 로직을 한 확장으로 합쳤습니다.
- **보완판 v1.0.21:** 소환 결과 `Glimmer` 번역을 추가했습니다.
- **보완판 v1.0.20:** 홈 캐릭터 화면의 UI 번역을 보완했습니다.
