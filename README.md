# Gacha Forge 한글화 보완판 v1.0.20

[원본 GACHA-FORGE-UI-KR](https://github.com/marittini/GACHA-FORGE-UI-KR)를 기반으로 한 비공식 번역 보완판이야.

## 변경 사항
- 홈 캐릭터 화면의 `Home unit`, `In use`, 속성/직업 표시 등 누락 번역 보완
- 4★ 캐릭터가 없을 때 나오는 영어 안내문 번역
- 기존 전투 상태 효과 및 UI 번역 유지
- 확장 표시 버전을 1.0.20으로 통일

## GitHub 확장 관리자로 설치
1. 마리나라에 [GitHub 확장 관리자](별도 설치 필요)를 설치해.
2. 마리나라 설정 → Addons → External Extensions → **GitHub 확장 관리**를 열어.
3. 이 저장소의 공개 GitHub 주소를 붙여넣고 **패키지 찾기**를 선택해.
4. `manifest.json` 기반 확장을 선택하고 코드와 권한을 검토한 다음 설치해.
5. 마리나라 기본 확장 화면에서 실행을 승인하고 페이지를 새로고침해.

업데이트할 때는 이 저장소에 새 버전의 `extension.js`와 `manifest.json`을 커밋하고, GitHub 확장 관리자의 **업데이트 확인**을 사용하면 돼.

> 기존 한글화 확장과 동시에 활성화하지 않는 것을 권장해.
